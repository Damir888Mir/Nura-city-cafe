# Nūra city cafe — сайт

Статический сайт городского кафе Nūra city cafe (Алматы, ЖК Novella, ул. Байзакова, 225).

- index.html — разметка (на русском)
- styles.css — стили и анимации
- script.js — прелоадер, анимации, вкладки меню, слайдер отзывов, лайтбокс, карта 2ГИС (Leaflet + тайлы 2ГИС)
- images/ — оптимизированные фото из Instagram @nura.citycafe

Деплой: Vercel, без сборки.
